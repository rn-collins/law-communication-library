# The Psychedelic Law Library

The Psychedelic Law Library: 143 plain-English articles on Oregon/Colorado law, facilitators, and psychedelic business. Built by RN Collins.

**Live:** https://law-communication-library.vercel.app

## Repository contents

`404.html`, `_astro`, `article-manifest.json`, `articles`, `index.html`, `robots.txt`, `sitemap.xml`, `sources.html`, `vercel.json`

## Local development

Static site. This repository contains prebuilt output (`_astro`); serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
